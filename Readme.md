1.What is the difference between var, let, and const?

Answer: When we use var it fix a space for a variable here the type of variable is not pre defined.
When we use let it fix a space for a variable which can be changed in any time. Here the variable can be number, boolean, string.
When we use const it fix a space for a variable which can not be changed in any time.Here the variable can be number, boolean, string.

3.What is the difference between map(), filter(), and forEach()?

Answer: This three operation is applicable for an array . Map() returns an array by using map we can apply any task for each of the elements of the mother array and the final output will be an array.
By using filter() we can filter elements from an array we can give or set a condition according to the condition we get the element in another array. It also returns another array.
By using forEach() we can set any operation for every element of an array and it can return anything.
